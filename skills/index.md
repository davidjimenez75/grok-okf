# Skills recomendados

Skills de agente (capacidades modulares) recomendados para implementar, basados en el perfil de programador/sysadmin con foco en Proxmox, LAMP, Debian, contenedores y grafos de conocimiento (OKF).

Cada skill incluye una explicación de por qué es útil, capacidades sugeridas y orientación de implementación.

* [proxmox-ops](proxmox-ops.md) - Operaciones y gestión de Proxmox VE
* [container-ops](container-ops.md) - Gestión de contenedores (LXC, Docker, Podman)
* [lamp-ops](lamp-ops.md) - Operaciones del stack LAMP (Apache, PHP, MariaDB)
* [okf-author](okf-author.md) - Creación y mantenimiento de bundles OKF
* [debian-sysadmin](debian-sysadmin.md) - Administración de sistemas Debian
* [impact-analysis](impact-analysis.md) - Análisis de impacto en sistemas y grafos de conocimiento
